# JASM-GameAssets

Game character metadata and images for [JASM](https://github.com/Moonholder/JASM).

This repository is consumed by JASM's **Game Asset Sync** feature, which incrementally downloads only changed files via a `manifest.json` file.

## How It Works

1. **CI** runs on every push to `main` and generates `manifest.json` with SHA256 hashes of all files.
2. **JASM client** downloads the remote `manifest.json`, compares with local version, and only downloads changed/new files.
3. Assets are served via **jsDelivr CDN** for fast global access, with **GitHub Raw + mirror** fallback.

## Contributing

To add or update game assets:
1. Place updated JSON files or images in the correct game directory
2. Push to `main`
3. CI will automatically regenerate `manifest.json`
